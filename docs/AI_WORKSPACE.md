# AI知识库与智能体工作台：第一批实现说明

本文件对应2026-10-18的实现。它是完整设计方案的阶段性交付，不代表全部规划功能已经完成。

## 1. 使用入口

### 局域网免登录演示

按用户要求新增显式演示模式，学生端导航不变，不增加管理入口。在启动后端的PowerShell中设置：

```powershell
$env:CAMPUS_WORKSPACE_DEMO_MODE = 'true'
npm run dev:server
```

开启后，同一WiFi下通过电脑局域网IP访问5173管理网页，无需登录；知识库和智能体页面直接加载数据库内容，并显示演示提示。这意味着能访问后端的人也能管理知识与模型配置，只能在可信开发网络使用，禁止公网映射。

恢复登录保护：将上述变量设为`false`并重启后端。默认不开启演示模式；前端根据后端返回的访问模式切换，不内置密码或伪造登录令牌。

- 知识库：`http://127.0.0.1:5173/#/knowledge`
- 智能体工作台：`http://127.0.0.1:5173/#/agents`
- 前端仍通过开发代理连接8088后端；无需数字孪生数据即可使用。
- 本地开发账号：`admin`，默认密码：`admin123`。可用后端环境变量`CAMPUS_ADMIN_PASSWORD`覆盖，修改后重新启动后端。
- 会话由服务端验证，8小时有效；服务重启后需重新登录。浏览器仅在当前会话保存令牌。

启动方式沿用README中的前后端启动步骤。新表由JPA更新创建；不会自动迁移或删除原知识记录，也不会自动生成正式知识、问答或模型配置。

所有工作台数据走后端和数据库；空库显示真实空状态。浏览器验收图片中的测试数据只存在于隔离的内存测试服务，不会写入业务MySQL。

## 3. 导入真实资料的流程

1. 登录并创建知识库，配置适用校区和人群。
2. 上传学校正式资料，补充可追溯来源，等待解析完成。
3. 进入切片管理，预览参数效果，确认生成切片；检查内容和页码。
4. 审核发布后，在检索测试中验证召回；停用后再次测试排除效果。
5. 高频且稳定的问题录入标准问答，审核后测试不同相似问法。
6. 创建智能体，绑定知识库，保存提示词，先验证无模型直答和检索。
7. 配置真实对话模型并完成连接测试，再调试RAG；确认结果后发布配置。

扫描PDF当前不做OCR，会明确提示需要OCR处理；DOCX中的图片内容不自动识别。不要用虚构页码或成功状态代替失败提示。

## 4. 接入大模型

当前支持兼容协议，不保证每家服务商的接口均可直接使用：

- 对话：基础地址后追加`/chat/completions`。
- 向量连接测试：追加`/embeddings`。
- 重排连接测试：追加`/rerank`。

在启动后端的终端中配置环境变量，值使用你自己的密钥，不要提交Git：

```powershell
$env:CAMPUS_LLM_API_KEY = '<你自己的服务商密钥>'
npm run dev:server
```

然后在模型连接页面填写真实基础地址、实际模型ID，以及环境变量名`CAMPUS_LLM_API_KEY`。不要在页面粘贴密钥值。已启动的后端无法读取后来设置的新环境变量，必须在该环境中重新启动。

连接测试会明确征求确认并发起真实请求，可能产生费用。本次开发仅验证了本地兼容协议测试服务，未使用任何云服务密钥，也未发生真实付费模型调用。

Embedding/Rerank连接测试成功不代表向量索引或重排已经启用。当前页面明确显示全文BM25，不伪装成混合检索。

## 5. API与数据结构

所有新接口位于`/api/workspace`，需要`Authorization: Bearer <token>`。登录使用`POST /api/auth/login`。

主要资源为`bases`、`documents`、`chunks`、`faqs`、`models`、`agents`、`releases`、`runs`。文档上传、切片预览/确认、审核动作、FAQ导入预览与提交、检索测试、发布/回滚、聊天调试均有独立接口。

新增表为`rag_base`、`rag_document`、`rag_chunk`、`rag_faq`、`model_connection`、`campus_agent`、`agent_revision`、`rag_run`（准确命名以实体注解为准）。上传文件默认存储在后端运行目录下的`data/knowledge`，由`campus.knowledge-dir`配置。备份时需同时备份数据库和该目录。

## 6. 自动化验收

本次结果：34项后端测试、4项浏览器端到端测试通过；Vue类型检查与生产构建通过。新增测试分别验证显式演示模式免登录与正式模式仍需鉴权。

后端覆盖真实PDF/DOCX解析、切片、审核与失效过滤、FAQ冲突/快速回答、条件澄清、导入预览不写库、缺失密钥拦截、发布回滚、鉴权，以及本地HTTP模型协议调用。

```powershell
npm run test:server
npm run build
```

浏览器验收先启动前端5173，再在另一终端启动专用8099测试服务：

```powershell
mvn -f server/pom.xml '-Dspring-boot.run.main-class=com.campus.freshman.rag.WorkspaceBrowserServer' spring-boot:test-run
```

该入口仅在测试源码中，使用H2内存数据库和系统临时上传目录，不连接业务MySQL。然后执行：

```powershell
npm run test:workspace
```

浏览器测试使用本机Microsoft Edge，覆盖问答直答、文档上传至发布检索再停用、智能体调试与发布、假PDF明确失败。完成后可关闭8099测试服务，保留正常8088业务服务。

## 7. 下一批与上线前限制

以下均未在本批冒充已完成：

- **索引第二阶段**：持久化/增量索引、Embedding向量入库、BM25与向量融合、重排、阈值校准。当前每次查询在内存构建BM25，适用于小规模验证，不适合大库高并发。
- **智能体深化**：多轮会话、SSE流式输出、模型自主工具循环、多任务拆解、所有TOOL类问答的实际工具绑定。当前仅独立路线意图有已有导航工具分支，不应视为完整多工具Agent。
- **质量中心**：评测集、离线指标、线上反馈、缓存与失效、限流预算、生产流量分析；目前日志仅为DEBUG，不计入学生咨询统计。
- **数据治理**：OCR、文档内图片理解、清洗规则编辑、更多格式、原文件浏览/下载。解析已有限制，但尚无独立沙箱进程和强制解析超时。
- **完整审计**：发布配置保留快照，引用记录保存ID；尚未保存每次回答的完整证据内容快照。已发布文档原地编辑被阻止，但停用后可编辑，历史知识还不具备全量不可变审计保证。
- **安全与权限**：当前只有管理员会话，新工作台接口鉴权；旧业务接口未整体改造，多角色RBAC、持久会话、审计脱敏、HTTPS、上传安全扫描与SSRF专门防护仍需上线前完成。模型服务地址仅允许可信管理员配置。
- **端侧接入**：学生手机端、原首页咨询助手仍保留原接口，不会自动切到新工作台配置；需要后续显式迁移和兼容验收。

建议下一批先做向量混合检索、重排与证据快照，然后完善工具调用和学生端接入，最后进行权限与评测上线验收。
